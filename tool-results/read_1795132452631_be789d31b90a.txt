    72→## Rules for running the prompts

    74→1.  Run the prompts **strictly in order**: 1.0, 1.1, 1.2, then Pack 2,
    75→    and so on. Each prompt reads files the previous one created.
    76→

    78→    Report. Read it. Answer any \"Decisions needed from me\" before
    79→    pasting the next prompt.

    81→3.  Prompt 1.0 makes the agent write the project rules into the
    82→    workspace (/docs/PROJECT_CONSTITUTION.md). Every later prompt starts
    83→    by re-reading those files, so the rules survive even if the chat is
    84→    restarted or the agent forgets.
    85→
    86→4.  If the agent says it cannot browse the web, **do not let it invent
    87→    research**. The prompts tell it to mark such items \"PENDING
    88→    RESEARCH\". You can paste source text or PDFs yourself, or use a
    89→    browsing-capable session for Prompts 2.1 and 2.5.
    90→
    91→5.  **Visual addendum:** a separate file, \"Visual and Motion
    92→    Addendum\", adds Prompt V.1 (run after 2.3, before any article is
    93→    written) and Prompt V.2 (run after articles exist). It guarantees
    94→    ultra-realistic, topic-specific images and graphic animations for
    95→    every article and segment. Prompts 2.4 and 2.5 will tell you to run
    96→    V.1 first if you forget.
    97→
    98→6.  If a prompt is too big for one reply, the agent is told to stop at a
    99→    safe point and say what remains. Reply \"continue\" and it will
   100→    resume.
   101→
   102→7.  Never paste real victim data while testing. Use fictional test data
   103→    only.
