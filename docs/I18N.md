# Internationalisation

English (`/en`) is the default. French (`/fr`) is a full locale, not a translation overlay.

Content uses JSON translation objects on each record (`translations.en`, `translations.fr`), with a locale-specific slug. If French is missing, the page falls back to English and shows a notice. The admin edit screen shows the current French title so an editor can see what is untranslated.

Interface chrome lives in `src/lib/i18n.ts`. The language switch uses a path map built from those slugs, so it stays on the equivalent page.

Search uses PostgreSQL `to_tsvector('simple', translations::text)` so both languages are searchable. This replaces the MySQL FULLTEXT indexes in the original brief.
